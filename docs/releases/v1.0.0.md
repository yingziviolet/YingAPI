# Ying 1.0.0

Ying 1.0.0 是首个可供 Windows 用户直接安装或解压运行的版本。

## 下载

- `Ying-Setup-1.0.0.exe`:推荐,带开始菜单与可选桌面快捷方式
- `Ying-portable.zip`:免安装,解压后运行 `Ying.exe`
- `SHA256SUMS.txt`:两个发布文件的 SHA-256 校验值

## 主要功能

- OpenAI 与 Anthropic 客户端兼容入口(OpenAI 兼容上游)
- 渠道故障自动切换、精确/语义缓存、虚拟 key、预算与限流
- React 控制台、首次启动引导、浅色/深色主题
- Windows 原生窗口、系统托盘、浏览器回退与单实例保护
- 用户数据保存在 `%LOCALAPPDATA%\Ying`;升级自旧版时继续复用已有 `%LOCALAPPDATA%\LLMGateway`

## 安装与升级

安装版直接运行 `Ying-Setup-1.0.0.exe`;便携版解压完整目录后双击 `Ying.exe`。
卸载程序不会删除数据库、密钥或日志。

当前安装包尚未使用商业代码签名证书。请只从本仓库的 GitHub Releases 下载,
并在运行前用 `SHA256SUMS.txt` 核对文件。
